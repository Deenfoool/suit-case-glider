# Чемодан-планер

Minecraft Java 1.20.1, Forge 47.4.28, Java 17. Установите JAR в папку mods выбранного профиля Forge; для сетевой игры мод нужен на сервере и клиентах. Дополнительные моды не требуются.

Выберите чемодан в основной руке. Обычный короткий прыжок его не раскрывает. При опасном снижении мод учитывает уже пройденное падение и расстояние до поверхности, раскрывает крыло и замедляет снижение. После касания земли планер складывается. Смена предмета прекращает полёт. В полёте атаки и взаимодействия заблокированы.

В первом лице на земле используется стандартное удержание предмета Minecraft. Раскрытие, полёт и складывание показывают сам планер без дополнительных рук. В третьем лице используется авторская модель с локтями и подбросом над головой; предмет не дублируется.

Рецепт на верстаке:

| Кожа | Кожа | Кожа |
|---|---|---|
| Палка | Нить | Палка |
| Палка | Пусто | Палка |

Окраска: чемодан и краситель в сетке крафта. Дерево и металл сохраняют цвет. Починка кожей; прочность 192, расход в полёте. Доступны «Прочность» и «Парение» до III. «Парение» уменьшает снижение, подъём и ракеты не предусмотрены.

Исходники: `gradlew.bat build` (JDK 17). Результат в build/libs. Запуск проверок: `gradlew.bat test`; серверная проверка в отдельном тестовом мире: `gradlew.bat runServer -Psmoke`. Режимы -Pvisual и -Prendercheck предназначены только для разработки и меняют отдельный тестовый мир.

Редактируемые модели находятся в соседней папке glider. Пользовательская правка ручки в carry_idle сохранена в steve_hand_glider_demo.bbmodel и перенесена в ресурс мода rigs/glider_scene.json. Подробные ограничения проверки фиксируются в verification.txt.
